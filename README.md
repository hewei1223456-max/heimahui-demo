# 黑马汇 · 交互演示

面向女装实体店主、供货厂家和平台运营的样例工作台。通过右上角身份菜单查看三种前台与两种网页后台。

- 店主可体验货源筛选、分批浏览、收藏、试拿清单、示例询货、订货会意向和规则诊断。打开款式再返回，可接着浏览原列表和已加载货源。
- 厂家可体验查看店主需求、样例联系、记入回访和经营总览。
- 平台可体验示例审核、活动展示控制及样例经营数据。渠道与推广可设置一张、多张或零张活动卡，牌面保留商业推广或平台推荐标识。

内容、商品、活动、价格及组织均为样例。收藏、意向、留言和报告保存在当前浏览器的演示空间。请使用样例文字。可从店主的「我的」重置这组记录。

通过静态 HTTP 服务提供本目录。线上示例由 GitHub Pages 提供，无需登录、安装或配置 API。网页源文件使用相对 URL 支持在仓库子路径运行。

首屏、选品和组货手记主图为原创示意摄影。演示图片不作为厂家实物凭证。
