# 黑马汇 · 交互演示

面向女装实体店主、供货厂家和平台运营的样例工作台。通过右上角身份菜单查看三种前台与两种网页后台。

- 店主可体验货源筛选、分批浏览、收藏、试拿清单、示例询货、订货会意向和规则诊断。筛选包含 14 个已登记产业带、10 类风格和开放价量区间。打开款式再返回，可接着浏览原列表和已加载货源。
- 经营专家咨询可选择八家大店案例方向并保存草稿。公开版的资料入口提供通用经营笔记。
- 从「数据测算专家」可打开毛利、贡献毛利、保本、库存周转和安全库存五种示例测算。数字仅在当前页面计算，刷新后重新输入。
- 店主的「我的」可切换六个新增示例门店。每家门店单独保存收藏和咨询记录。双方发起后可重开同一对话，也可从会话查看对方示例主页。
- 厂家后台默认打开「厂家运营后台」，第二项「货源广场」浏览完整示例目录。「查看我的货源数据」打开本厂样例数据。
- 平台可体验示例审核、活动展示控制及样例经营数据。渠道与推广可设置一张、多张或零张活动卡，牌面保留商业推广或平台推荐标识。

内容、商品、活动、价格及组织均为样例。收藏、意向、留言和报告保存在当前浏览器的演示空间。请使用样例文字。可从店主的「我的」重置这组记录。

线上示例由 GitHub Pages 提供，无需登录、安装或配置 API。网页使用相对 URL 支持在仓库子路径运行。本地预览从项目根目录运行 `node scripts/prepare-preview-build.mjs <空的输出目录>`，通过静态 HTTP 服务提供导出目录。导出时直接复制共享测算引擎。

首屏、选品和组货手记主图为原创示意摄影。演示图片不作为厂家实物凭证。
